# AI Operating Rules

1. Read this file before changing the project.
2. Read `project/overview.md` to understand the site scope.
3. For visual work, read `design/figma-notes.md` and `design/tokens.md`.
4. For icons or images, read `assets/icons.md`.
5. For HTML, CSS, or JS edits, read `code/conventions.md` and `code/file-map.md`.
6. If a design or implementation choice becomes stable, add it to `decisions/decision-log.md`.
7. Before saying work is done, run through `qa/checklist.md`.

Keep context files short and factual. Prefer updating existing notes over duplicating the same rule in multiple places.
