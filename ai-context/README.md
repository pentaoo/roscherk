# AI Context

This folder stores project knowledge that an AI assistant should re-read before making changes.

Use it as the stable source of truth for:

- project goals and constraints;
- Figma and design notes;
- asset and icon rules;
- code conventions;
- decisions already made;
- QA checks and current tasks.

Before editing the site, read `00-operating-rules.md` and then the files relevant to the requested change.
