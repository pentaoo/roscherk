# Project Overview

## Scope

Static website with:

- `index.html` for markup;
- `styles.css` for layout and visual styles;
- `script.js` for client-side behavior;
- `source/icons/` for local SVG icons.

## Current Notes

- The icon pack is stored locally.
- Icon file names match the names used in Figma.
- The project currently has no build step.

## AI Guidance

Preserve the simple static structure unless a requested feature clearly requires tooling.
